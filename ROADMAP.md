## 2. API: Kinopoisk Unofficial

- Базовый адрес: `https://kinopoiskapiunofficial.tech/api/`
- Авторизация: заголовок `X-API-KEY: <ваш ключ>`
- Лимит: без общего суточного лимита, около 20 запросов в секунду на пользователя (по описанию клиентских библиотек, сверить в документации)
- Точные эндпоинты (коллекции, поиск, детали, трейлеры) **сверить по Swagger на их сайте** перед написанием Retrofit-интерфейса

Что нужно приложению:
- [ ] Списки (популярное, топ, ближайшие релизы)
- [ ] Поиск по названию
- [ ] Детали фильма
- [ ] Актёры и съёмочная группа
- [ ] Трейлеры/видео
- [ ] Фильтры (год, жанр, рейтинг), если останется время

**Безопасность ключа:**
- хранить в `local.properties`: `KP_API_KEY=...`
- читать через `BuildConfig`
- `local.properties` должен быть в `.gitignore` (в новом проекте так по умолчанию)
- не отправлять ключ в чаты, issue и скриншоты

## 3. Архитектура

```
data/remote   KinopoiskApi (Retrofit), DTO
data/local    Room: FavoriteEntity, CachedMovie, DAO
data/repo     MovieRepository (интерфейс) -> KinopoiskRepository
              (позже: TmdbRepository / OmdbRepository)
domain        Movie, MovieDetails
ui/           home, search, details, favorites, freemovies, settings, theme, components
di/           Hilt-модули
```
Главное правило: UI знает только `MovieRepository`. Источник данных можно заменить без переписывания экранов.

## 4. Бесплатный просмотр (легальный)

Каталог Кинопоиска даёт только метаданные, не видео. Для просмотра нужен отдельный легальный источник.

| Источник | Что даёт | Как подключить | Статус |
|---|---|---|---|
| **Blender Open Movies** (Big Buck Bunny, Sintel, Tears of Steel, Spring) | Полные короткометражки, лицензия CC BY | Скачать и разместить на своём хостинге, отдавать через Media3/ExoPlayer, указывать авторство | основной |
| **Internet Archive** (общественное достояние) | Классика, старое кино | `archive.org/advancedsearch.php`, `/metadata/<id>`, прямая ссылка на mp4. Только заранее проверенный список из 5-10 фильмов | основной |
| **Официальные YouTube-каналы** с бесплатными фильмами | Полные фильмы | Встраивание через YouTube-плеер, нужно проверить, разрешает ли канал встраивание | проверить |
| Платные сервисы (Okko, Kinopoisk HD и т.д.) | Только ссылка «где смотреть» | Открывать их страницу или приложение | идея, без плеера |

Задачи:
- [ ] Выбрать 5-10 фильмов для раздела «Смотреть бесплатно»
- [ ] Вручную проверить лицензию каждого фильма на его странице (общественное достояние или CC)
- [ ] Занести список в JSON (id, название, постер, ссылка, лицензия, авторство)
- [ ] Экран плеера на Media3: полноэкранный режим, запоминание позиции
- [ ] Отобразить лицензию и авторство в карточке фильма
- [ ] Не использовать неофициальные «кинотеатры» и пиратские стримы
