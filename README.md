# Plenka

Каталог фильмов для Android: популярное, поиск, избранное, офлайн-кэш, тёмная и светлая темы.
Демонстрационное приложение для портфолио.

<!-- Сюда 5-6 скриншотов: главная, детали, поиск, избранное, настройки, светлая тема -->

## Возможности

- Главная с постраничной подгрузкой при прокрутке
- Поиск с задержкой 400 мс, подсказки, отмена устаревших запросов
- Экран фильма: постер под статус-баром, рейтинги Кинопоиска и IMDb, жанры, раскрывающееся описание
- Избранное в Room, добавление и удаление в один тап
- Офлайн: списки и результаты поиска кэшируются, при пропаже сети показываются сохранённые данные
- Настройки: тема (как в системе / светлая / тёмная, сохраняется), очистка кэша
- Анимированный сплэш, собственные векторные иконки, анимации переходов между вкладками

## Стек

Kotlin, Jetpack Compose, Material 3, Navigation Compose, Hilt, Room, DataStore,
Retrofit + OkHttp + Gson, Coil, Coroutines и Flow.

## Архитектура

Clean Architecture + MVVM. UI знает только интерфейс `MovieRepository`, источник данных можно заменить без переписывания экранов.

```
data/remote      Retrofit-интерфейс и DTO
data/local       Room: избранное и кэш
data/settings    DataStore: настройки
data/repository  реализация репозитория
domain           модели и интерфейсы
ui               экраны, навигация, тема, общие компоненты
di               модули Hilt
```

## Запуск

1. Получите бесплатный ключ на [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech/).
2. Добавьте в `local.properties` (файл не попадает в Git):
   ```
   KP_API_KEY=ваш_ключ
   ```
3. Откройте проект в Android Studio и запустите на устройстве или эмуляторе (minSdk 26).

## Данные

Данные о фильмах предоставляет Kinopoisk API Unofficial. Приложение не связано с Кинопоиском.
